## 🛠️ 環境準備

你可以使用以下任何一種環境來執行筆記中的 C# 程式碼：

- **IDE / 編輯器**：Visual Studio 2022 / Visual Studio Code / JetBrains Rider
- **.NET SDK**：.NET 6.0 或更高版本 (推薦 .NET 8)
- **線上編譯器**：[dotnetfiddle.net](https://dotnetfiddle.net/)

:::info 📌 快速學習建議
建議複製筆記中的程式碼至控制台應用程式（Console App）中的 `Program.cs` 檔案進行單步偵錯（F11 Step Into），這樣能最直觀地觀察遞迴呼叫過程與記憶體變數的變化。
:::
