# 🔵 Lesson 2: 基本算術運算

在這一課中，我們將學習如何在 C# 中進行基本的數學運算。請特別注意整數除法與浮點數除法的差異！

---

## 💻 範例程式碼

```csharp
using System;

class Program {
    static void Main() {
        // 1. 加法 (+)
        Console.WriteLine(3 + 4);  // 輸出: 7

        // 2. 減法 (-)
        Console.WriteLine(5 - 6);  // 輸出: -1

        // 3. 乘法 (*)
        Console.WriteLine(9 * 10); // 輸出: 90

        // 4. 除法 (/)
        // 注意：整數除以整數，結果會自動捨去小數點
        Console.WriteLine(12 / 4); // 輸出: 3
        Console.WriteLine(13 / 4); // 輸出: 3 (小數點後被捨去)
        
        // 若要得到精確的小數結果，至少要有一個數是浮點數 (double)
        Console.WriteLine(13.0 / 4); // 輸出: 3.25

        // 5. 餘數 (%)
        // 用於取得除法後的餘數
        Console.WriteLine(12 % 4); // 輸出: 0
        Console.WriteLine(13 % 4); // 輸出: 1
    }
}
```

---

## 🖥️ 預期輸出 (Expected Output)

執行程式後，控制台 (Console) 將會顯示以下內容：

```text
7
-1
90
3
3
3.25
0
1
```

## 📌 本課重點總結 (Summary)

:::note 重點摘要
1. **算術運算子**：
   - `+` (加)、`-` (減)、`*` (乘)、`/` (除)、`%` (取餘數)。
2. **整數除法陷阱**：
   - 當兩個 `int` 進行除法時，C# 會捨去小數點（例如 `13 / 4` 得到 `3` 而不是 `3.25`）。
   - 若需精確的小數結果，請確保至少有一個運算元是 `double`（例如 `13.0 / 4`）。
3. **餘數運算子 (`%`)**：
   - 用於計算除法後的餘數，常用於判斷奇偶數或循環邏輯。
:::
